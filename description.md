# Описание проекта lab4SUV-Beibutov

## Назначение

Учебный репозиторий для лабораторной работы № 4 по дисциплине
«Системы управления версиями» (МТИ, направление 09.04.03 «Прикладная информатика»).
На нём отрабатывается работа с удалёнными репозиториями GitHub:
клонирование, синхронизация изменений (push, pull, fetch) и командная
разработка по модели Fork & Pull Request.

## Состав репозитория

| Файл | Назначение |
|------|------------|
| `main.py` | Основной скрипт проекта, выводит приветствие |
| `README.md` | Краткое описание репозитория и выполненных этапов |
| `description.md` | Подробное описание проекта и порядка совместной работы |
| `.gitignore` | Правила исключения служебных файлов из контроля версий |

## Порядок внесения изменений

1. Сделать fork репозитория и склонировать его.
2. Создать ветку под задачу: `git checkout -b feature/<краткое-имя>`.
3. Зафиксировать изменения и отправить ветку в свой fork: `git push origin feature/<краткое-имя>`.
4. Открыть Pull Request в ветку `main` исходного репозитория.
5. После Code Review и слияния синхронизировать fork с исходным репозиторием (`upstream`).
