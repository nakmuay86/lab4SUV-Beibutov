# lab4SUV-Beibutov

Репозиторий для лабораторной работы №4 «Работа с Git и GitHub».

## Что сделано

### Этап 1. Создание и клонирование репозитория
- Настроены глобальные параметры Git (`user.name`, `user.email`).
- Сгенерирован SSH-ключ (`ssh-keygen -t ed25519`) для подключения к GitHub.
- Репозиторий создан на GitHub и клонирован на локальный компьютер.
- Проверены удалённый репозиторий (`git remote -v`) и ветки (`git branch -a`).

### Этап 2. Синхронизация изменений
- Проверено состояние репозитория (`git status`).
- Файл `main.py` добавлен в индекс (`git add`) и зафиксирован (`git commit`).
- Изменения отправлены на сервер (`git push origin main`).
- Файл `README.md` создан и изменён в веб-интерфейсе GitHub без создания новой ветки.
- Правка получена локально командой `git pull origin main`.

## Структура репозитория

- `main.py` — основной скрипт
- `README.md` — описание репозитория
